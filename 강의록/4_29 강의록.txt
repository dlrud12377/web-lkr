 < 복습 >
	* 부분함수 종속
	기본키의 일부만으로 종속되는 경우
	학번	과목코드	학생이름	과목명
	1	DB		김철수	데이터베이스
	-> 학번 상관없이 과목코드만으로 과목명이 결정되어버림

	* 이행함수 종속
	A -> B, B-> C면 A -> C가 되는 관계

	학번		학과코드		학과명
	1		D01			컴퓨터공학

	학번 -> 학과코드, 학과코드 -> 학과명 일때
	학번 -> 학과명
	- 학과명이 중복저장될 수 있다.
	- 수정 이상이 발생한다.

	* 이상현상
	- 데이터베이스 설계가 잘못되어 데이터를 삽입, 수정, 삭제할 때 비정상적인 문제가 발생하는 현상

		* 삽입 이상
		- 데이터를 추가하려고 할 때, 필요 없는 데이터까지 강제로 넣어야 하는 문제

		학생번호	학생명	과목명	교수명
		1		김철수	DB		이교수
		NULL		NULL		PYTHON	김교수

		- 과목만 추가하고 싶은데 학생 정보까지 필요함

		* 수정 이상
		- 같은 데이터가 여러 번 저장되어 일부만 수정하면 데이터의 일관성이 사라지는 문제
		학생번호	학생명	과목명	교수명	강의실
		1		김철수	DB		이교수	301
		2		이영희	DB		이교수	301
		3		박민수	DB		이교수	301 // 모두 교수명, 강의실이 동일

		* UPDATE TABLE
		SET 강의실 = '401'
		WHERE 학생번호 = 1

		-> 이렇게 되면 데이터가 하나만 수정이 되는데, 이 경우 같은 데이터여야 하는 부분이 다른 데이터가 되어버리게 된다.(변경이 같이 되어야 하는 상황에도)

		* 삭제 이상
		- 데이터를 삭제할 때, 유지되어야 할 다른 정보까지 같이 삭제되는 문제
		학생번호	학생명	과목명	교수명
		1		김철수	DB		이교수

		1명이 수강을 하고 있는데 김철수가 수강을 철회했음
		- 학생정보가 삭제되는데 이 때 DB과목 존재 정보가 같이 삭제됨
