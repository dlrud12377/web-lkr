** 복습 < 예외 >
 - 예외들이 클래스 형태로 존재함
 - Exception 클래스의 자식 클래스

 < 예외처리 형태 >
	try { 예외 발생 가능성이 있는 코드 }
	catch(AnyException e) 예외 발생 시 실행코드(주로 예외상황 출력 및 전달) }
		 - catch 구문은 체크하고 싶은 예외가 여러가지일때 반복 작성 가능
		 - Exception이라고 쓰면 모든 예외를 catch 가능 - 하지만 가장 먼저 발생하는 한 가지의 예외만 catch함
	finally { 예외 상황과 관계없이 무조건 실행되는 코드 - writer.close 등의 예외 발생 가능성이 있는 코드가 들어간다면 이중 try문을 사용하기도 함}

근데 예외 발생 시점에 모든 코드가 스탑되니 하나만 잡을 수 있는데, 한번 실행으로 모든 예외를 잡을 수 있는 코드 구성은 없을까?
 - 없음.. 메서드별로 끊어쓰는게 최선(gpt 코딩 보고 구조 체크하기)

 < 사용자 정의 예외 만들기(CustomException) >
	 - 문법 상에 오류는 없으나 프로그램 설계 상 허용되지 않는 경우 - 예외를 강제로 발생시키는 것
	 - 그냥 if문 쓰면 되지 않나요?

 	< if문 처리 >
		- 프로그램 안에서 자연스럽게 처리가 됨
		- 정상적인 흐름 안에서 처리함(ex. 로그인 성공/실패)
		- 단순 검증(예상 가능한 흐름)

	< 예외 >
		- 오류를 처리
		- 잘못된 상황임을 정확히 인지시킴

 	* setter의 값 거르기 때 써도 되나, 트래픽적으로 무리가 가기 때문에 필요한 부분에 선택과 집중이 필요


 < Object 클래스 관련 문법 및 메서드 >
	- equals() : 주소가 같은지 비교
	- hashcode() : 주소를 반환
	- toString() : 화면에 출력을 어떻게 할 것인지
	
	대부분의 클래스들이 위 메서드들을 오버라이딩하여 상황에 맞게 사용함

 < 롬복 설치 >
	1. 이클립스가 설치된 곳에 롬복파일 넣기
	2. 롬복 파일 실행하기
	3. 이클립스 실행파일 설정하고 설치하기
	4. 이클립스가 켜져 있다면 껐다 켜기
	5. 같은 프로젝트에 옮기고 build path 넣고 모듈info 넣기 / or 클래스패스에 넣고 사용
