 < 예외처리 형태 >
	try { 예외 발생 가능성이 있는 코드 }
	catch(AnyException e) 예외 발생 시 실행코드(주로 예외상황 출력 및 전달) }
		 - catch 구문은 체크하고 싶은 예외가 여러가지일때 반복 작성 가능
		 - Exception이라고 쓰면 모든 예외를 catch 가능 - 하지만 가장 먼저 발생하는 한 가지의 예외만 catch함
	finally { 예외 상황과 관계없이 무조건 실행되는 코드 - writer.close 등의 예외 발생 가능성이 있는 코드가 들어간다면 이중 try문을 사용하기도 함}

근데 예외 발생 시점에 모든 코드가 스탑되니 하나만 잡을 수 있는데, 한번 실행으로 모든 예외를 잡을 수 있는 코드 구성은 없을까?

 < Object 클래스 관련 문법 및 메서드 >
	- equals() : 주소가 같은지 비교
	- hashcode() : 주소를 반환
	- toString() : 화면에 출력을 어떻게 할 것인지
	- exit() : 프로그램을 종료시키는 메서드. 어떤 숫자를 넣어도 종료가 되나, 비정상적인 종료는 1이나 -1, 정상적인 종료는 0을 통상적으로 넣음
	
	대부분의 클래스들이 위 메서드들을 ""오버라이딩""하여 상황에 맞게 사용함

 < 자바에서 제공하는 클래스 정리 >


- System : 출력, 입력과 관련된 클래스
	- in : 입력
	- out : 출력
	- err : 에러 출력

- Math : 수학 관련 클래스(ceil, floor, round, pow, random, max, min)
	- ceil(num) : 올림
	- floor(num) : 내림
	- round(num) : 반올림
		- 3개 모두 소수 첫째자리에서 반올림해야 하기때문에 다른 자리 반올림이 필요하면 10의 제곱수를 곱하고 double형 10의 제곱수를 나누어 조절을 해야함
	- pow(x, y) : x의 y승
	- random() : 0 <= x < 1 사이의 랜덤 난수 생성
	- max(x,y) : x,y 중 더 큰 값
	- min(x,y) : x,y 중 더 작은 값

- StringBuilder : 수정되지 않는다는 규칙 때문에 자주 변경하면 메모리에 버려진 문자열이 많아짐 -> 기존 문자열 정보를 자주 수정해야 하는 상황에서는 stringbuilder를 써서 메모리 절약을 해주면 좋음(buffer 시스템을 통해 이전 문자열을 수정하거나 추가하여 사용하기 때문)
	- append() : 맨 뒤에 추가
	- insert() : 내가 원하는 위치에 추가
	- delete() : 내가 원하는 만큼 삭제
	- reverse() : 문자열 뒤집기
** buffer : 데이터를 한 번에 처리하지 않고 임시로 저장하는 공가
- StringTokenizer : 구분자가 1개라면 문자열을 잘라서 가지고 있는 것(split과 유사하나, 한 종류의 구분자만 가능)
	- hasMoreTokens() : 남아있는 문자열이 있는지 여부(boolean)
	- nextToken() : 문자열을 하나씩 가져옴

- Wrapper : Integer, Double, Long.... 처럼 포장하는 클래스(기본 변수를 객체화함)
	- Integer -> int 등의 상황은 자동형변환이 일어남
	- Integer Character Byte Lone Float Double Boolean

- currentTimeMillis(), nanoTime() : 시간을 체크하는 메서드. nanoTime이 좀더 정밀함
- LocalDateTime : 날짜와 시간을 읽고 조작하기 위해 사용(시간을 관리하는 자료형)
	- LocalDateTime.now() : 현재 날짜와 시간을 반환
	- of(년, 월, 일, 시, 분) : 특정 날짜 생성
	- get시간개념() : 각 개념을 반환(날짜, 시간, 분, 초 등등)
	- withYear(), withHour() : 연(날짜) / 시간 수정
	- isBefore(), isSame(), isEqual() : 두 시간을 비교하여 빠른지 느린지 같은지 비교(boolean)
	- LocalDate : 날짜만 / LocalTime : 시간만


- 정규표현식(Regular Expression)
	- 문자열의 "패턴"을 정의하는 규칙
	- 특정 문자열이 내가 원하는 형식으로 적혀있는지 검사
	- a-z, A-Z, 0-9 : 소문자, 대문자, 숫자 검사
	- 가-힣 : 한글 전체 검사
	- ? : 없거나 한개
	- + : 한개 이상
	- [] : 안에 적힌것 중 한개 ( ex) [abc] : a,b,c 중 한개 )
	- Pattern.matches(정규식, 문자열) -> boolean 반환
	- 문자열.matches(정규식) : 1회성 검사
