상속
ㄴ 관련있는것들끼리 묶는 것
공통적인 속성(필드, 멤버)이나 동작(메서드)을 부모쪽에 몰아놓는 것

자식은 부모 클래스를 상속받아서 사용
is-a 관계
강아지는 동물이다. ("dog" is an "animal")
N차 상속이 가능함 (연쇄상속)
다중 상속은 불가능함
Object : 모든 클래스의 부모클래스

Arrays.toString(배열)

sealed : 봉인된 클래스
permit : 내가 지정한 클래스만 상속을 할 수 있게 허용한다.


인터페이스
일반 필드 x
상수, 추상메서드, 디폴트메서드, 정적메서드,. private 메서드
ㄴ 동작에 대한 가이드라인 제공
같은 범주에 있는 것들이 아니어도 상관x (기능들에 대한 짧은 브리핑 느낌)
fly();
class Bird{};
class Airplane{};

- 추상클래스와 마찬가지로 직접 객체를 만드는 것이 불가능하다.
 -> 인터페이스를 구현할 클래스가 있어야 한다.
	형식 : class impl implements 인터페이스명{};

- 추상메서드를 반드시 오버라이딩해야 한다.

- 다중 구현이 가능하다.(추상클래스와 다른점)
class Impl implements interface1, interface2{};
- 각 인터페이스에 있던 추상메서드를 전부 오버라이딩 해야한다.

- 다중 상속이 가능하다.
	- 상속은 인터페이스 끼리만 가능하다.
		형식 : interface interA extends interB, interC
 - (????) 인터페이스 타입의 변수에 넣는 것은 가능하다.

중첩 클래스
 - 많이 사용되지는 않지만 특정한 상황에서 쓰인다.
 - when?
	1. 클래스 내부에서만 쓰는 전용 객체인 경우(외부에 공개할 필요가 없거나 공개하면 안되는 것)
	2. 강한 결합(항상 같이 움직이는 구조) - 두 클래스가 절대 분리되지 않을 때

정적 내부 클래스
 - 내부클래스인데 static이 붙은 형태
 - 바깥 객체에 소속된 내부 클래스처럼 보이지만, 실제로는 바깥 객체 없이도 독립적으로 만들 수 있는 내부 클래스
