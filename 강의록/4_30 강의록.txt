 < 복습 >
	< MySQL >
		- 관계형 데이터베이스
		- 테이블 형태로 데이터를 관리(릴레이션)
		- 행(ROW) : 가로 데이터셋(한 건의 데이터)
			ㄴ 행의 개수 : 카디널리티
		- 열(COLUMN) : 세로 데이터셋(한 가지의 데이터)
			ㄴ 속성(Attribute)

 	< SQL >
		- Structured Query Language : 데이터베이스에 저장된 데이터를 다루기 위한 언어
		- 추가, 조회, 수정, 삭제를 주로 함
	
	< SQL의 종류 >
		- DDL : 데이터베이스 객체를 조작하는 SQL
			- CREATE
			- ALTER
			- DROP

		- DML : 테이블 내의 데이터를 조작하는 SQL
			- SELECT : 테이블 내의 데이터를 조회하여 보여준다.
			- INSERT : 테이블에 데이터를 추가한다.
			- UPDATE : 테이블 내의 데이터를 수정한다.
			- DELETE : 테이블 내의 데이터를 삭제한다.

		- DCL : 권한 관리 명령어
			- GRANT : 권한을 주는 명령어
			- REVOKE : 권한을 회수하는 명령어

		- TCL : 트랜젝션 케어
			- COMMIT
			- ROLLBACK

		< 트랜젝션 > : 여러 SQL 작업을 하나의 작업 단위로 묶는 것
			- EX) 계좌이체
			- A계좌에서 10만원 이체
			- B계좌에서 10만원 입금

			- MySQL은 기본적으로 AUTO COMMIT MODE임. 따라서 START TRANSACTION 명령어를 적어주어야 함

			START TRANSACTION; - 임시로 반영하기 명령어
			QUERY CODE1
			QUERY CODE2

			마음에 들면 COMMIT;
			안들면 ROLLBACK;

		< 제약조건 >
		- 테이블에 잘못된 데이터가 들어가지 않도록 막는 규칙
			1. PK - PRIMARY KEY (기본키) - NOT NULL & UNIQUE

			2. NOT NULL - 값을 비우지 못하게 함

			3. UNIQUE - 중복된 값을 넣지 않도록 함

			4. FOREIGN KEY (외래 키) - 다른 테이블의 기본키를 참조하는 제약조건
			ㄴ 없는 데이터를 참조하지 못하게 하는 규칙

			5. CHECK - 특정 값만 조건을 만족하도록 제한하는 제약조건

			6. DEFAULT - 값을 입력하지 않았을 때 자동으로 들어갈 기본값 설정

	< 모델링 >
		- 현실 세계의 데이터를 데이터베이스 구조로 설계하는 과정
		요구사항분석
		개념모델링 - 엔티티의 결정 (ERD 작성)
		논리모델링 - ERD를 보고 자료형이나 제약조건 설정, 정규화(1~5차)
		물리모델링 - 코드를 작성하여 실제 테이블로 만드는 과정

	
	< SQL함수 >
		- 단일 행 함수 : 1개의 행 값이 함수에 적용되어 1개의 행을 반환하는 것
		- 집계 함수 : 1개 이상의 행 값이 함수에 적용되어 1개의 행을 반환한다.

		< 문자함수 >
			- LENGTH(COLUMN) : COLUMN 데이터의 바이트 수 반환

			- CHAR_LENGTH(COLUMN) : COLUMN 데이터의 글자 수 반환

			- UPPER(), LOWER(COLUMN) : 대/소문자로 변환
로 변환
			- TRIM(), LTRIM(), RTRIM() : 양쪽 공백 제거, 왼쪽 공백 제거, 오른쪽 공백 제거

			- LPAD(), RPAD() : 문자열의 자리수를 지정, 남으면 특정 문자열로 채운다.

			- SUBSTRING(), SUBSTR(), MID(COLUMN, X, Y) : 문자열 자르기(X부터 Y길이만큼)
			* MySQL에서 인덱스(X)는 1부터 시작
			* 음수 인덱스 존재(-1부터 시작, 뒤에서부터)

			- LEFT(COLUMN, X), RIGHT() : 문자열을 왼쪽 / 오른쪽부터 내가 원하는만큼(X만큼) 자른다.

			- INSTR() : TARGET 문자열이 어디에 있는지 위치번호를 반환
			
			- CONCAT(STR1, STR2...) : 나열된 문자열의 연결

			- REPLACE(COLUMN, OLDTARGET, NEWWORD) : 문자열에서 특정 문자열을 다른 문자열로 교체(등장하는 모든 문자열을 교체해줌)
			* 교체할 문자열이 없으면 바뀌지 않은 상태 그대로의 문자열을 다시 반환함

			SUBSTRING_INDEX(문자열, 구분자, 개수) : 문자열을 특정 구분자를 기준으로 잘라서 원하는 부분만 가져오는 함수
