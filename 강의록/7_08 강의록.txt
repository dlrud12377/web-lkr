1. 구현된 UI의 사용성 테스트 시 '사용자가 의도한 대로 시스템의 반응이 적절하게 구현되어 있는지', '사용자가 예상할 수 있는 행위와 일치하는지' 확인해야 한다.
만약 테스트 환경의 시스템 반응이 실제 운영 환경과 다르게 구동될 경우, 이것이 실제 사용자의 행태와 환경을 이해하는 데 어떤 문제를 야기하는지 서술하시오.

 - 테스트 환경의 시스템 반응이 사용자의 의도나 예상과 다르게 구동되면, 사용자가 시스템이나 기능에 맞춰 적응하거나 새로 학습하도록 유도되는 결과를 낳는다.

 - 이는 사용자의 한계 능력과 상황에 맞추어 디자인하는 '사용자 중심 디자인'의 최적화 목적에 어긋나며, 사용자의 편의성이 충분히 고려되었는지 최종 검증하는 것을 방해한다.

2. '개발자들은 당연히 알고 있을 수 있지만 사용자들은 모를 수 있는 전문 용어들이 사용되는 등 개발자들이 간과하기 쉬운 실수'를 확인해야 한다.
이를 바탕으로, 테스트 환경에서 실제 사용자의 속성에 가까운 사람들을 참여시키지 않고 내부 관계자의 시각으로만 데이터를 구축, 테스트했을 때, 제품의 배포 전 최종 검증 단계에서 어떤 치명적인 맹점이 발생하는지 서술하시오

 - 개발자가 내부 제작자는 시스템의 구조와 전문용어에 익숙하여 본인들이 간과한 실수를 스스로 발견하기 어렵다
실제 시스템을 사용하게 될 사용자의 속성에 가까운 사람들이 참여하지 않으면, 일반 사용자의 관점에서 시각적으로 명확하게 구별되는지, 행동이 자연스럽게 유도되는지 객관적으로 확인할 수 없다.
결과적으로 실제 운영 시 발생할 수 있는 잠재적인 문제점들을 현실적이고 정확하게 도출해 내지 못한 채 제품을 배포하게 되는 맹점이 발생한다.

3. 테스트 진행자들이 테스트 참여자들이 테스트하는 테스트룸의 위치를 알지 못하도록 테스트룸과 관찰실을 공간적으로 격리하여 구성한다
이처럼 두 공간을 물리적으로 엄격하게 격리해야 하는 이유를 '테스트 결과에 미치는 영향' 관점에서 서술하세요.

 - 테스트 진행에 참여하여 관찰하는 사람들 중 개발자 등과 같이 시스템의 개발에 직접적으로 연관이 있는 사람들이 테스트 참여자와 접촉할 경우, 테스트 결과에 영향을 끼칠 수 있다.

 - 테스트 진행에 참여하여 관찰하는 사람들 중에는 개발자 등과 같이 시스템의 개발에 직접적으로 연관이 있는 사람들이 포함되어 있다.
만약 공간적 격리가 이루어지는 대신 이들이 테스트 참여자와 직접 접촉하거나 시선, 행동 등이 노출될 경우 테스트 참여자의 자연스러운 행동에 방해를 주어 테스트 결과에 왜곡된 영향을 끼칠 수 있기 때문이다.
따라서 도중에 테스트가 중단되지 않고 독립된 상태를 유지하기 위해 공간을 엄격히 격리해야 한다.

4. 프로젝트의 규모, 또는 확보된 사용성 테스트 예산을 고려하여 사용성 테스트 참여자의 인원을 확정해야 하는 현실적인 제약이 존재한다.
그럼에도 불구하고 현실적이고 정확한 결과를 얻기 위해 가능한 한 명 이상의 테스트 참여자를 확보해야 한다는 원칙을 달성하기 위해, 참여자를 리스트에서 최종적으로 선정할 때 최우선으로 반영해야 하는 '선정 기준'은 무엇인지 서술하시오.

 - 한정된 예산 안에서 최적의 인원을 선정하려면, 무작위 추출이 아니라 "대상 제품"을 사용할 가능성이 있는 사람들을 대상으로 해야 한다.(EX. 핸드백 브랜드 - 여성 중산층 이상(경쟁제품을 사용해본 사람))
 - 실제 시스템을 사용하게 될 사용자의 속성에 가까운 사람들로 참여자를 제한하여 최종 선정함으로써, 최소한의 인원으로도 현실적이고 정확한 테스트 결과를 도출할 수 있도록 조율해야 한다.

문제 5
테스트 환경을 구축하기 전 "구현된 UI에 대해서 사용성 테스트의 목적과 필요성, 그리고 중요성에 대해서 이해관계자들 간에 인식을 공유"하는 단계가 선행된다.
이 공유 단계가 누락된 채 테스트 환경이 구축될 경우, 배포 전 최종 검증이라는 본질적 목표 측면에서 어떤 문제가 발생할 수 있는지 서술하세요.

 - 서로 사용성 테스트에서 검증하고자 하는 포인트가 달라진다. 이는 사용성 테스트에서 증명하고자 하는 목표점을 흐리게 만든다. 이로 인해 상호적인 연계의 추진이 모호해지고, 잠재적인 문제를 미리 예측 및 대책 수립을 하기 위한 관리 및 변인 통제가 되지 않는다.

 - 이해관계자 간에 목적과 중요성에 대한 인식이 공유되지 않으면, 구축된 테스트 환경이 '최초 개발된 의도대로 잘 구현이 되었는지', '세부 기능들이 정확하게 작동하는지'를 검증하는 명확한 기준을 상실한다.
이로 인해 테스트 영역 간의 상호 연계 추진이 모호해지고, 결과적으로 실제 운영시 발생할 수 있는 잠재적 문제를 예측하고 미리 대책을 세우기 위한 '효과적인 관리와 환경 통제'가 불가능해진다.


문제 6. 제이콥 닐슨의 5가지 사용성 요건 중 사용효율성과 기억용이성의 개념을 비교하여 서술하고, 각 요건을 계획서에 반영할 때 측정할 수 있는 지표를 각각 1가지씩 제시하세요
 - 사용효율성은 사용자가 서비스의 구조에 대해 숙련된 후, 원하는 목적을 얼마나 신속하고 생산적으로 달성하는지를 의미하는 개념이다. 그래서 예시가 되는 지표는 태스크 완료 시간 또는 클릭/터치 및 페이지 이동 횟수 등을 예로 들 수 있다.
 반면 기억용이성은 기존에 이용했던 사용자가 오랜 시간이 지나 이전의 사용 방법을 기억하지 못하는 상태에서 간단한 조작으로 이를 다시 기억해 낼 수 있는가에 대한 개념이다. 그러므로 예시가 되는 지표는 재방문자의 태스크 수행 속도, 메뉴 탐색 헤맴 빈도(비정형 행동 측정) 등이 있다.

 - 사용자가 주어진 미션을 최종적으로 성공했는지, 실패했는지만을 명확하게 규정하여, 데이터의 주관성을 배제하기 위함이다.

문제 15.
NEM 기법의 개념을 설명하고, 왜 '초심자'와 '숙련자'의 수행 시간을 함께 비교하는 것이 제품의 문제를 객관적으로 파악하는데 도움이 되는지 서술하시오.

 - NEM 기법은 제품을 처음 사용하는 초심자와 설계 및 개발에 참여한 숙련자를 사용성 테스트에 참여시켜서 대상 제품의 태스크 수행시간을 비교하여 문제점을 객관적으로 제시하는 사용성 테스트 기법이다.

초심자와 숙련자의 수행 시간을 비교하면 숙련자와 초심자의 수행 시간이 비슷하게 나올수록 학습 용이성이 검증이 되며, 반대의 경우에는 초심자만이 겪게 될 수 있는 숨겨진 사용성 문제를 발견할 수도 있다. 즉 격차를 분석함으로써, 단순히 "시간이 오래 걸린다"를 넘어 "특정 UI 구조나 다지안이 초심자에게 얼마나 비직관적이고 불필요한 인지적 노력을 요구하는지"를 객관적인 수치로 드러내 주기 때문이다.
