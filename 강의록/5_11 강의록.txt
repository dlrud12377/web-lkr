< Stored Program >
 - MySQL 서버 안에 저장해두고 실행하는 프로그램의 단위(일종의 함수, 메서드 개념)
	 - 프로시저 : 여러 SQL 작업을 묶어서 실행하는 프로시저
	 - Function : 값을 계산에서 반환하는 함수
	 - Trigger : INSERT, UPDATE, DELETE 발생할 때 자동 실행되는 문법
	 - Event : 정해진 시간마다 자동 실행되는 문법

	* Stored Program 문법
		 - MySQL 안에서 프로그래밍 언어처럼 SQL을 실행하기위한 문법

		문법의 종류
		 - 변수
 		 - 조건문
 		 - 반복문
		 - 예외처리
		 - 커서
		 - BEGIN ~ END 블록

 < Procedure(프로시저 : 과정) >
 - 여러 개의 SQL문을 하나의 이름으로 저장하고, 필요할 때 호출해서 실행하는 기능

 - 자주 사용하는 SQL을 간단하게 사용할 수 있다.

 - 기본 구조
DELIMITER //
CREATE PROCEDURE 프로시저명(매개변수 - INOUT)
BEGIN
	SQL문;
END //
DELIMITER ; -- 드래그 후 ALT+X로 실행

 - 매개변수
IN : 외부에서 값을 받아서 프로시저 내부로 전달
OUT : 내부에서 도출된 값을 프로시저 밖으로 전달
INOUT : 값을 받아서 수정한 뒤 다시 외부로 전달

 - 매개변수 기입 형식
키워드 변수명 자료형,
키워드 변수명 자료형...

 - 세션 변수
	 - 전역변수(static 변수 느낌)
	 - 현재 MySQL 접속에서 사용할 수 있는 변수
	 - 사용방식 : @변수명

 - declare로 선언하는 지역변수
	- 형식 : declare 변수명 자료형 default 기본값;
	- 선언위치는 begin 바로 아래여야 한다.
	- set 변수명 = 값;
	- set 변수명 = (sql문)
	- select 컬럼 into 변수명 from 테이블

 - IF문

 - 형식
 - IF 조건 *THEN* 실행문;
 - ELSEIF 조건 THEN 실행문;
 - ELSE 실행문;
 - END IF; (IF문 종료)

 - CASE문
	- 조건에 따라 다른 값을 반환하거나, 다른 처리 흐름을 만들 때 사용하는 조건문

 - IF VS CASE
	1. 사용 위치
	IF문 : 프로시저 내부에서만 사용 가능
	CASE문 : SELECT절, 프로시저 내부 모두 사용 가능

	2. 주 용도
	IF문 : 실행 흐름을 제어
	CASE문 : 조건별 처리

 - 기본 문법
	CASE
		WHEN 조건식1 THEN 결과1
		WHEN 조건식2 THEN 결과2
		WHEN 조건식3 THEN 결과3
		ELSE 기본결과
	END


 - MySQL의 경우는 ~

WHILE
LOOP
~
REPEAT : 최소 1번 실행 후 조건 검사

 반복문을 사용하는 구조
 변수 : 반복횟수를 저장
 조건식 : 반복 종료를 판단
 SET : 변수 증가
 LEAVE : 반복 종료
 ITERATE : 다음 반복으로 이동
