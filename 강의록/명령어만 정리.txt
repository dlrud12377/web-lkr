명령어만 정리

데이터베이스 만들기
CREATE database IF NOT EXISTS academy_db
character set = utf8mb4
collate = utf8mb4_unicode_ci;

의미
CHARACTER SET
이 데이터에서 문자를 저장할 기본 문자셋(Encoding)을 지정
utf8mb4가 MySQL에서 가장 안전한 유니코드 문자셋이다.

COLLATE
정렬과 비교의 기준을 설정



테이블 만들기

create table [if not exists] 테이블명 (
	컬럼명 변수타입,
	[컬럼명 변수타입,]
);

in-line 제약조건 주기
변수명 변수타입 primary key
장점 : pk와 같이 겹치지 않는 간단한 제약조건 주기 좋음
단점 : 여러 칼럼 한번에 제약 불가, 이름 자동생성으로 인해 수정 삭제가 어려움

constraint 제약조건 주기
constraint 제약조건명 제약조건(제약조건을 걸 칼럼들)

테이블, 유저, 컬럼
 -> drop으로 없애기

그 외 데이터의 경우
 -> delete로 없애기

칼럼 추가, 삭제, 변경 등등 테이블을 변경해야 되면 alter table 붙이기

	1. 칼럼  추가/삭제하기
		- alter table 테이블명 add column 컬럼명 변수타입[, 컬럼명 변수타입...];

	2. 칼럼 삭제하기
		- alter table 테이블명 drop column 컬럼명;

	3. 칼럼명 변경하기
		- alter table 테이블명 rename column 이전 칼럼명 to 바꿀 칼럼명;

	4. 칼럼의 타입 변경하기
		- alter table 테이블명 modify column 컬럼명 바꿀 타입;

	5. not null, unique는 칼럼의 속성으로 분류되어 바꿀 때 modify를 씀

	6. 제약조건 추가하기
		- alter table add 제약조건 (대상컬럼);

	7. 제약조건 삭제하기
		- alter table drop 제약조건

	8. 테이블에 걸린 제약조건 보기
		- show index from 테이블명;
