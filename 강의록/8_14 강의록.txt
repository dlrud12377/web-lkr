자바
 - 객체 만들 때 new 예약어를 통해 객체를 메모리에 올리기 위한 공간을 달라고 요청
 - GC(Garbage Collector)가 사용되지 않는 객체를 자동으로 메모리에서 제거
 - 메모리 오류 위험이 적다.

C
 - 메모리를 얼마 공간만큼 할당해달라고 직접 요청(함수)
malloc(sizeof(int) * 4)
*malloc : memory allocation
 - free() 함수를 이용해서 메모리에서 해제
 - 상대적으로 메모리 오류 위험이 크다.
 - 메모리가 유연하지는 않지만 최적화에 좋다(섬세함 / 할당된 만큼만 메모리를 사용하기 때문)
 - 언어 자체가 가벼움

메모리 누수 : 메모리를 점유했는데 해제가 안된 것

C -> 클래스 / 객체, 상속, 오버로딩, 예외 처리 개념이 없음
C++ -> 객체 지향을 지원, new 사용
C# -> C와 C++의 문법적 영향을 받았지만, 실행 방식과 메모리 관리 측면에서는 Java와 상당히 비슷하다.
