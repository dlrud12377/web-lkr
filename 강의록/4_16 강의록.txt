 < 4/16 강의록 >

	< 복습 >

	< 경로 >
		- 절대경로 : 윈도우 기반으로 경로를 설정
		- 상대경로 : 현재 프로젝트 기반으로 경로를 설정

	< 입출력 >
		- 데이터를 읽거나 내보내는 행위(합쳐서 IO라고 부름. 자바 클래스도 io)
			-Input : 데이터를 외부에서 읽어 오는 것
			-Output : 데이터를 외부로 내보내는것

		- 바이트 기반의 스트림
			- 데이터를 바이트(byte) 단위로 읽거나 내보내는 스트림
			< FileInputStream >
				- 외부에서 파일의 내용을 읽어오는 클래스
				- 생성자에 경로 (FileNotFoundException 예외가 발생할 수 있다.)	
				- read() : 데이터를 1바이트 읽어와 int로 저장한다.
				- read(byte [b])를 통해서 읽어온 내용을 바이트 배열에 저장한다.
				- new String(byte[] b) 문자열 생성자를 통해 내용을 문자열로 반환한다.

				- 장점
					1. 모든 파일을 처리할 수 있다. (이미지, 영상, 텍스트)
					2. 인코딩의 영향을 받지 않는다.

				- 단점
					1. 한글의 경우는 한글자에 1바이트가 아니기 때문에 바이트기반 스트림으로 읽어오기가 쉽지 않다.
					-> 따라서 문자 기반의 스트림을 쓰는 것이 좋음.
