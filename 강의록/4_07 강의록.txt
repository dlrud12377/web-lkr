 < 4/07 강의록 >

 < Class 클래스 >
	- 클래스에 대한 정보를 얻고 싶을 때 사용한다.
	- 필드, 메서드, 생성자에 대한 정보도 얻을 수 있다.

 < 어노테이션@ >
	- 코드에서 @를 붙여 작성되는 요소를 어노테이션이라고 한다.
	- 클래스 또는 인터페이스를 컴파일 또는 런타임 시 어떻게 사용할지 이야기하는 역할을 한다.
	- ex -> @Override(메서드 재정의 - 오버라이딩 어노테이션)

	- 어노테이션을 직접 만드는 일은 거의 없음
	- 그러나 자바에서 제공하거나 라이브러리가 제공하는 어노테이션을 사용하는 일이 많음
	- Override, FuntionalInterface, Getter/Setter, ..constr, Controller, Service, Repository, RequestParam, ResponseBody, Entity

< 제네릭 >
 - 매개변수 등의 타입을 메서드 내가 아니라 외부에서 지정하는 것

	< 중첩 타입 파라미터 >
	- 제네릭 안에 제네릭 타입이 들어가는 구조
	- 형식 : Outer < Inner <T> >
	- 복잡한 데이터 구조 표현 가능
	- 타입 안정성 유지
	- 객체 관계를 명확하게 표현

	<제네릭 메서드>
	- 메서드 자체가 타입을 일반화해서 받는 메서드
	- 클래스 전체를 제네릭으로 만드는 게 아니라 특정 메서드 하나만 필요할 때 타입을 유연하게 처리하는 방법
	- 기본 문법 : 접근제한자 < T > 반환타입 메서드명(매개변수) {code}

	< 타입 추론 >
	- 제네릭 메서드를 호출할 때 전달한 값으로 타입을 자동 판단한다.
		- cf) 명시적으로 타입을 부를 때 - p.<String>printValue("안녕"); - 제네릭을 . 뒤에 붙여준다
