	- 람다식을 만드는 것 : 추상메서드를 오버라이딩 하는 것과 동일	
	
	< java 함수형 인터페이스 >
		- 람다식을 쓰기 위해서는 함수형 인터페이스가 필요하나, 필요할 때마다 만들어 쓰기가 부담스러움
		- 그래서 java에서 자체적으로 자주 쓸 수 있는 함수형 인터페이스를 만들어 둠
	
		< 종류 >
			- Function<T,R> - R apply(T t) : 매개변수가 1개고 반환값이 있는 메서드
			- Consumer<T> - void accept(T t) : 매개변수가 1개, 반환값이 없는 메서드
			- Supplier - T get() : 매개변수가 없고, 반환값이 있는 메서드
			- Predicate - boolean test(T t) : 매개변수가 1개, 반환값이 논리형인 메서드

			- 제네릭이 2개 필요하면 Bi를 붙임(BiConsumer, BiPredicate, BiFunction... )

		< 람다식의 합성과 결합 >
			1. Function
				- f.andThen(g) : f를 실행하고 g를 실행함 (f dot g)
				- f.compose(g) : g를 실행하고 f를 실행함 (g dot f)

			2. Predicate
				- f.and(g) : f, g 두 람다식의 결과가 참이어야 true를 반환(and 연산자의 개념)
				- f.or(g) : f 또는 g의 결과가 참이어야 true를 반환(or 연산자의 개념)
				- negate() : false면 true, true면 false로 바꾼다(not 연산자의 개념)
