실습 시나리오

한 학원에서 기존 수강 관리 시스템의 문제점을 해결하기 위해 새로운 시스템 구축 프로젝트를 진행하려고 한다.

현재 시스템에는 다음과 같은 문제가 존재한다.

- 모바일 사용이 불편하다.
- 출결 처리 속도가 느리다.
- 문자 발송 실패가 자주 발생한다.
- 상담 이력이 통합 관리되지 않는다.
- 관리자마다 사용하는 프로그램이 다르다.
- 수강료 결제 내역이 자주 누락된다.

여러분은 요구사항 확인 단계에서 현행 시스템을 분석하고, 요구사항을 정리하는 업무를 담당한다.

2. 개선해야 하는 기능 3개 작성

- 현재 시스템에 존재하지 않는 기능이어야 한다.
- 실제 쇼핑몰에서 사용할 수 있는 현실적인 기능이어야 한다.
- 기존 문제를 해결하거나 사용자 편의성을 높일 수 있어야 한다.

작성 예시
배송 조회 기능
- 현재 문제: 모바일 화면이 깨져서 사용하기 어렵다.
- 개선 방향: 반응형 UI를 적용하여 모바일 환경에서도 정상적으로 보이도록 수정한다.

로그인 기능
 - 현재 문제 : 보안이 취약하여 보강이 필요하다.
 - 개선 방향 : 
	1. 정규식을 사용한 로직으로 좀 더 복잡한 비밀번호를 요구한다.
	2. 위치나 배열이 랜덤으로 변경되는 전용 가상 키보드를 사용하게 하여 UI 패턴의 단순화를 탈피할 수 있도록 구성한다.
	3. OTP를 활용할 수 있도록 보안 관련 앱을 따로 만든 뒤, 이를 앱으로 연동시켜 로그인 때마다 사용하도록 유도한다.
		- 보안 관련 앱은 로그인 시 인증을 지문인식이나 사용자가 지정한 방식으로 간단하게 할 수 있도록 만든다.
		- 추가로 로그인/로그아웃 기록 및 ip를 확인하고, 원격 로그아웃 기능을 통해 잘못된 접속을 차단할 수 있도록 한다.
		- 편의사항 : 추가로 보안 시스템 사용자는 지정PC, 앱 자동 로그인 기능을 활용할 수 있도록 기능을 구현한다.

상품 조회
 - 현재 문제 : 검색속도가 느리다.
 - 개선 방향 : 
	1. 데이터베이스에서 사용할 수 있는 index를 체크하여, 파트별로 세분화한 뒤 더 빠르게 정보를 선별하여 전달할 수 있도록 구성한다.
	2. 응답 속도 향상을 위해, 트래픽 처리 통로를 늘린다. 또는 위의 세분화된 Index를 통해 EAI 구조로 전달할 수 있도록 데이터베이스 파트별 통로를 설정한다.
