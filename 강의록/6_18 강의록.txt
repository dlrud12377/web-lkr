Reset CSS
브라우저가 자동으로 넣어주는 기본 여백, 목록, 점, 링크 밑줄, 버튼 모양 등을 제거해서 모든 브라우저에서 비슷한 출발점으로 디자인하기 위한 CSS

Normalize CSS
브라우저의 기본 스타일을 완전히 제거하는 것이 아니라, 브라우저마다 다르게 적용되는 부분을 통일해주는 CSS

사용방법
1. 태그에 직접 지정하는 방법
2. CDN 사용

중앙 정렬
 - 화면이나 부모 요소 기준으로 콘텐츠를 가운데 배치하는 기술
 - 웹페이지의 레이아웃에서 가장 많이 사용하는 정렬방식 중 하나이다.
 - 버튼, 팝업, 로그인 폼 등 주요 요소를 강조할 때 많이 사용한다.

컨테이너

flexbox : 자식 요소를 내가 원하는데로 정렬할 수 있는 속성
flex를 설정하는 주체를 부모요소 또는 컨테이너
속성에 영향을 받는 요소를 item이라고 한다.

컨테이너 관련 속성
flex-direction : 주 축을 결정
flex-wrap : 가로 너비가 좁아지면 밑으로 내릴거냐
justify-content : 주 축에서 요소들의 정렬방법을 설정
align-items : 교차 축에서 요소들의 정렬 방법을 선택



1. 다음 시맨틱 구조를 사용한다
    - `header`, `nav`, `main`, `section`, `aside`, `footer`
2. `header`에는 사이트 제목을 넣는다
3. `nav`에는 메뉴 3개를 만든다(`ul` 과 `li` 로 만들어 주세요)
4. `main` 안에는 `section`(본문)과 `aside`(보조 정보)를 가로로 배치한다
5. Flexbox를 사용하여 `section`은 폭의 70%, `aside`는 30%가 되도록 한다
6. `footer`는 페이지 가장 아래 가로 전체로 배치한다
7. 영역별로 배경색을 다르게 지정하고, 텍스트를 중앙 정렬한다

### 힌트

- Flexbox의 부모 컨테이너: `display: flex;`
- 자식 간 간격: `gap`
- 공간 분배: `flex: 비율`
- 가로 중앙 정렬: `justify-content: center;`
- 세로 중앙 정렬: `align-items: center;`
