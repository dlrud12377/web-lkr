 < 제어문 >
	1. 조건문 : 조건에 따라 실행할 명령을 결정한다. (ex. if, switch)

		(1). if문 - 조건의 "범위"를 통해 제어
		 - 기본형 : if (조건식) {조건에 맞을 시 실행할 코드}
		 - if : 조건에 따라 실행할 지 말지 결정
		 - if - else : 참일때 실행할 명령과 거짓일 때 실행할 명령을 할당
		 - if - else if : 여러 조건을 비교하여 실행할 명령을 결정

		(2). switch문 - 조건의 "일치함"을 통해 제어. -> 연속성이 있는 실수는 사용 불가
		 - 기본형 : switch(button) 
				{ case button1 : 버튼과 버튼1이 같을 시 실행할 코드; break;
				  case button2 : 버튼과 버튼2가 같을 시 실행할 코드; break;

					...
				  default(선택) : 모든 버튼과 case의 버튼이 일치하지 않을 시 실행할 코드;
				}

		 - 초기화와 함께 사용 : Type 변수명 = switch(button) 
				{ case button1 -> code;
				  case button2 -> code;
					...
'				  default(필수) -> code;
				};


	2. 반복문 : 조건에 따라 명령을 반복할지 말지 결정한다. (ex. while, for)
