 < 4/09 강의록 >

	< 컬렉션 프레임워크 >
		 - 프레임워크 : 
		
	인터페이스 구성요소 : 상수, 추상메서드
		-> List 인터페이스
			- 순서가 있다.(index 존재)
			- 중복이 가능하다.
			- 넣는대로 들어간다.

		<대표 클래스>
			- ArrayList : List 인터페이스를 구현한 대표적인 클래스
				ㄴ 조회에는 유리하나 추가/삭제는 불리함
			- LinkedList


 	< Set >
		- 같은 값은 한 번만 저장할 수 있다.
		- 저장된 데이터의 순서를 보장하지 않는 경우가 많다.
		- key와 value 두 개의 값으로 구성된다.
		- Set, HashSet이 대표적인 구현 클래스

	 < Iterator(반복자) >
		- 컬렉션 개체를 순회하면서 하나씩 꺼내는 기능
		- 지우는 기능
		- 인덱스가 없는 Set에 내용을 꺼낼 때 유용하다.
		- List<Integer> list = new ArrayList<>();
		- list.iterator(); -> 이런식으로 이터레이터를 만들어서 씀
		- hasNext() : 다음에 출력할 요소가 있으면 true / 아니면 false
		- next() : 다음 요소를 반환(커서 개념 - next 실행때마다 하나씩 뒤로 감)

		- 향상된 for문도 내부에서 반복자를 기반으로 동작을 함
		- iterator를 사용하면 내부에서 삭제를 하면서 반복문을 돌리는 것이 가능(원래는 안됨)

	< Collections 클래스 >
		- 컬렉션을 사용하는 데 있어 유용한 기능들을 가지고 있는 클래스
		- 직접 객체를 생성하지 않는다.
		- 모든 메서드는 static으로 선언이 되어있다.
		- 데이터를 저장하기보다는 가공/처리하는 역할

		- 오름차순 정렬 : sort()
		- 내림차순 정렬 : sort(list,reverseorder())
		- 뒤집기 : reverse();
		- 최대최소(문자의 경우 사전순) : max(), min()
