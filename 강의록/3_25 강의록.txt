		 - break : 해당 명령어를 반복문 내에서 만나는 순간 즉시 반복문을 종료하게 만듦
		 - continue : 해당 명령어를 반복문 내에서 만나는 순간 남은 내용을 모두 무시하고 증감식으로 돌아감
		 - outer : 기타 제어문은 가장 가까이 있는 반복문에 대해 적용이 되는데, 중첩 반복문에서 outer를 지정하면 내가 깨고 싶은 반복문을 지정할 수 있음

 <문자열(String)>
		1. 문자열(String) : 저장한 문자열을 가리키는 참조형 변수
				-> 클래스이고, 클래스 내에서 사용하는 기능들이 메서드 형태로 정의되어 있음

		2. 선언 방식
			(1). 묵시적 객체생성 : 같은 문자열이면 객체를 공유함
				String s1 = "홍길동";
				String s2 = "홍길동";  -> s1 == s2
			
			(2). 명시적 객체생성 : 항상 새로운 객체가 만들어짐. 문자열이 같아도 다른 객체 판정(주소가 다름)
				String s3 = new String("홍길동");
				String s4 = new String("홍길동"); -> s3 != s4

		3. String의 메서드 -> 자바 파일에서 자세히 확인
			(1). charAt(index); : 문자열에서 문자 추출하기
			(2). length : 문자열의 길이 측정
			(3). replace("기존", "새로운"); : 특정 문자열을 대체
			(4). substring(시작 index, 끝 index); : 문자열 잘라내기
			(5). indexOf("문자열"); : 위치 찾기
			(6). split("기준값"); : 문자열을 분리 - 반환값 Array
			(7). contains("문자열"); : 특정 문자열을 포함하고 있는지 - 반환값 boolean

 < 배열(Array) >
		1. 배열(Array) : 여러 개의 자료를 묶어서 저장하는 참조형 변수
		
		2. 선언 방식
			- int[] arr = {1, 2, 3, 4, 5}; // 배열을 선언함과 동시에 초기화 리스트를 사용
			- int[] arr2; // 배열 선언만 -> 선언 후 초기화 리스트를 대입할 수는 없다.
