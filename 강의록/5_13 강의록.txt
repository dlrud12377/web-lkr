 < 복습 >
	< Stored Program >
		- MySQL에서 프로그래밍적으로 동작하는 프로그램
		- 프로시저 -> 여러 개의 sql을 한 번에 처리할 수 있는 함수(method)
		- function -> 값을 반환하는 함수(method without void)
		- handler -> 예외처리
		- cursor -> iterator
		- trigger -> insert, update, delete와 같은 테이블 데이터 변경문이 실행되었을 때 이벤트의 처리


 < JAVA, MYSQL 연동하기 >
 - Java가 MySQL과 연결이 되려면 JDBC Driver가 필요하다.
 - jdbc(java database connectivity) driver
	- java 프로그램과 데이터베이스를 연결해주는 통로 역할을 함
	- java와 DB를 연결
	- SQL을 전달하는 역할
	- 결과를 받아오는 역할

 - DBMS 회사마다 JDBC Driver가 다르다
 	 - MySQL : mysql-connector-j
	 - Oracle : ojdbc
	 - PostgreSQL : postgresql
