파일 소유권
 - 어떤 사용자와 어떤 그룹이 그 파일의 주인인가를 나타내는 정보

소유 사용자(User Owner)
 -  해당 파일의 대표 사용자

소유 그룹(Group Owner)
 - 해당 파일과 관련된 대표 그룹
 - 같은 그룹에 속한 사용자들은 그룹 권한 범위 안에서 접근할 수 있다.

왜 파일 소유권이 필요한가
 - 보안과 역할 분리 때문이다.

리눅스에서 파일은 누가 만들면 주인이 되는가?
 - 기본적으로는 파일을 만든 사용자가 그 파일의 소유자

파일 소유권은 어디서 확인하는가
 - 파일 소유권은 ls -l 명령어로 많이 확인함

사용자는 기본 그룹 외에도 여러 그룹에 추가로 속할 수 있다.

리눅스는 사용자와 그룹 정보를 파일로 관리한다.

/etc/passwd
- 사용자 목록과 기본 정보가 들어있는 파일
- 암호화된 비밀번호 정보가 저장되는 곳이다.

/etc/shadow
- 민감한 사항이기 때문에 일반 사용자는 볼 수 없다.
- 비밀번호가 평문으로 저장되지 않고 암호화된 상태로 저장된다.

/etc/group
- 그룹 정보 저장

현재 로그인한 사용자의 이름을 확인

현재 사용자의 UID, GID, 속한 그룹까지 확인하는 명령어

파일 허가권
~

누가 접근하는가
user : 파일의 소유자
group : 파일이 속한 그룹
other :  그 외 모든 사용자

무엇을 할 수 있는가
권한의 종류는 3가지이다.
r : read, 읽기
w : write, 쓰기
x : execute, 실행

파일에서의 r,w,x의 의미
r(read)
 - 파일의 내용을 읽을 수 있다.
 - 텍스트 파일 열기
 - cat을 이용하여 내용 보기
 - 프로그램이 파일 내용 읽게하기

w(write)
 - 파일의 내용을 수정할 수 있다.
 - 내용 추가, 내용 삭제, 내용 덮어쓰기

x(execute)
 - 파일을 실행할 수 있다.
 - 쉘 스크립트 실행
 - 실행 파일을 실행

디렉토리에서 r, w, x의 의미
r : 디렉토리 내 어떤 파일이 있는지 목록을 볼 수 있다.
w : 디렉토리 안에서 파일 생성, 삭제, 이름 변경을 할 수 있다.
x : 디렉토리 안으로 들어갈 수 있는 권한


예시
drwxrwxrwx 1 adminn adminn    4096 Apr 20 15:17  Desktop
분석

- rw-(owner) r--(group) r--(other)

첫글자 : 파일의 종류
- : 일반 파일
d : 디렉토리
l : 링크

rw-(owner) : 소유자는 읽기, 쓰기만 가능하다.
r--(group) : 그룹은 읽기만 가능
r--(other) : 다른 사용자는 읽기만 가능

권한을 숫자로도 표현할 수 있다.
우분투에서는 권한을 문자 대신 숫자로 표현하기도 한다.

각 권한에 숫자를 부여한다.
r = 4
w = 2
x = 1

이 값을 더해서 표현한다.
rwx = 4 + 2 + 1 = 7
rw- = 4 + 2 = 6
r-- = 4
r-x = 4 + 1 = 5

허가 변경하기
chmod 권한값(owner, group, other) 파일명
권한값은 위처럼 7, 6, 5, 4 중 하나

chmod 644 memo.txt

소유자 : rw-
그룹 : r--
기타 : r--

문자 방식
u : user
g : group
o : other
a : all

+ : 권한 추가
- : 권한 제거
= : 권한을 지정한 값으로 설정

chmod u+x test.txt
소유자에게 실행 권한을 추가

chmod g-w memo.txt
그룹의 쓰기 권한을 제거

chmod o-r memo.txt
기타 사용자의 읽기 권한을 제거

파일 소유자가 아니면 권한을 바꿀 수 없다.

파일 소유자 변경하기
chown(change owner)

sudo chown 새소유자 파일명

일반 사용자는 자기 마음대로 소유자를 바꾸지 못하고 관리자 권한이 필요하다.

디렉토리에서 하위 파일까지 한 번에 소유권 변경하기
디렉토리 안에 파일이 많을 때는 -R 옵션을 사용한다.
sudo chown -R 사용자:그룹명 디렉토리명
