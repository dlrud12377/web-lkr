객체지향 프로그래밍(Object-oriented Programming)
 - 프로그램을 객체 단위로 나눠 설계하고 구현하는 방식

객체지향을 하지 않을 때의 문제점

객체 지향의 핵심 개념
1. 클래스(class)
 - 설계도, 직접 만든 참조 자료형
ex) 이 프로그램에서 대상을 어떻게 정의할 것인지 field와 method를 이용하여 설계
	-클래스 내에는 필드와 메서드를 정의함
		- 필드 : 각 객체가 가지는 정보(이름, 나이, 키, 몸무게, 성별, 주소..)
		- 메서드 : 각 객체가 할 수 있는 동작(공부한다, 먹는다, 운동한다, 잔다..)
2. 객체(object)
 - 클래스라는 설계도를 통해 만들어진 물건(field의 기본정보와 method의 행동양식을 가짐)
 - 사용법
	 - 필드 : 객체변수.필드
	 - 메서드 : 객체변수.메서드();

3. 객체지향의 4대 특징
 - 캡슐화
	 - 데이터를 보호하는 개념
	 - 필드에 직접 접근하지 못하게 함(보안)
	 - 제공된 메서드를 통해서만 접근할 수 있게 한다.
	 - getter, setter

 - 상속
	 - 기존 클래스의 내용을 물려받는 기능(필드, 메서드)
	 - 코드를 재사용할 때 좋음

 - 다형성
	 - 하나의 타입으로 여러 객체를 다룰 수 있는 성질
	 - 오버라이딩

 - 추상화
	 - 클래스를 단순화 시키는 것

 < 클래스 - 메서드 >
	 - 메서드 내부에서 메서드를 정의할 수는 없음
	 - 메서드 외부에서 메서드를 호출하는 것은 불가능함
