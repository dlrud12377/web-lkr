< 데이터 타입 >

1. 자료형의 종류
 (1). 기본 자료형 - 값 자체를 들고 있음(ex. 정수형, 문자형, 실수형, 논리형(boolean))
 (2). 참조 자료형 - 값이 있는 주소값을 알고 있음(ex. Integer, String, Double...)


2. 기본 자료형 1 - int(정수형)
 - 32bit(4byte) 사이즈 정수 자료형
 - 2^16개의 정수 정보를 담을 수 있음(-2^8 ~ 2^8 -1)

int var1 = 0b1011; // 2진수 11;(앞에 0b를 적어주어야 함)
int var2 = 0206; // 8진수(앞에 0을 적어주어야 함)
int var3 = 365; // 10진수
int var4 = 0xB3; // 16진수(앞에 0x를 적어주어야 함) - B : 11 -> 11 * 16 + 3 = 179


3. 기본 자료형 2 - byte(정수형)

 - 8bit(1byte) 사이즈 정수 자료형
 - 2^8개의 정수 정보를 담을 수 있음(-128~127)
 - 정수의 경우 해당 자료형이 표현할 수 있는 범위를 벗어난 데이터를 저장하면 오버플로우, 언더플로우가 발생할 수 있음
ex) byte var1 = (byte) -129; // 타입캐스팅, 127


4. 기본 자료형 3 - float, double
 - 소수 표현을 위해 쓰는 실수 변수
 - 기본적인 실수 리터럴 값은 double 취급
 - float는 4byte, double은 8byte 사이즈
 - float을 쓸 경우 숫자 뒤에 f를 붙여 float타입임을 명시해야 함
 ex) float f1 = 0.6789f;
 - 10의 거듭제곱 사용 시 e 사용
 ex) double d2 = 3e6; // -> 3 X 10^6을 의미
 - double type이 좀 더 정밀한 작업시 유용함


5. 기본 자료형 4 - 논리형(boolean)
 - 참거짓을 나타내는 변수, 1bit 사이즈

6. 기본 자료형 5 - char
 - '' 사용하여 한 글자 정보를 나타내는 변수. ex) 'A'
 - 2byte 사이즈
 - 정수형 변환 시 유니코드를 사용하여 변환됨(A-> 65, a-> 97..)

7. 참조 자료형 1 - String
 - char c1 = "홍길동"; -> 3글자(6bit), ""는 char값이 받아들이지 못함
 - 이렇게 여러 글자를 사용하는 경우 String 사용
 - 데이터를 변수에 넣어서 사용하는 이유 : 재사용이 가능함 + 데이터 일괄 수정에 용이(코드의 지속성)

< 형변환(Type Casting) >

1. 자동 타입 변환(명시적 형변환)
 - 작은 자료형 -> 큰 자료형으로 바꾸려고 할 때 사용
 - 자동으로 변환이 된다.


2. 강제 형변환(명시적 형변환)
 - 큰 자료형 -> 작은 자료형으로 바꾸려고 할 때 사용
 - 상황에 따라서는 자료형이 맞지 않아 오버/언더플로우가 일어날 수 있음. 또는 미스매치가 발생도 가능함(내가 생각한 결과와 다른 결과가 나올 수 있으므로 주의)
 - 바꾸려는 타입을 적어주어야 함 / ex. (타입) (변수명) = (**바꾸려는 타입**) (기존 변수)
 - 실수 -> 정수 -> 문자

< Print >

1. print - 띄어쓰기 없음, 줄바꿈 없음(가장 기본적인 형태)
- 줄바꿈하려면 println 또는 \n 사용

2. println - 문장 끝에 줄바꿈이 있음

3. printf
 - 문자열 속에서 데이터를 출력할 수 있는 메서드
 - 데이터는 자료형에 따라 서식문자를 이용해 출력
	정수 : %d (decimal)
	실수 : %f (float)
	문자형 : %c (character, char)
	문자열 : %s (String)
	논리형 : %b (boolean)
	// %.xf : 소숫점 x째 자리까지 출력
	// %xd : x자리 공간을 확보한 채 정수 출력
	// %0xd : x자리 공간에 정수 출력, 빈 공간에 0 삽입

< Input(Scanner) >

 - import java.util.Scanner : 자바에 있는 Scanner 클래스를 불러옴
 - cf) import java.util.* : 자바 util에 있는 모든 클래스를 불러옴
 - Scanner sc = new(메모리에 공간 확보) Scanner(System.in)(확보된 공간에 Scanner 객체 생성); 이렇게 **객체를 생성하여 사용
 - System.in : 키보드 입력을 받는 기본 통로
 - next : String 입력
 - next~ : Int(정수 입력), Line(모든 String 입력), Double(실수 입력)....

< 연산자 >

 1. 단일 연산자
	1-1. 부호연산자 : -(마이너스)
	1-2. 증감연산자 : ++(더하기 1), --(빼기 1)
 	- 증감연산자의 경우 위치에 따라 전위연산(먼저 계산하여 그 줄 식에 적용), 후위연산(줄 식에 적용 후 증감 계산) 두 가지가 있음

	// Q.
	x = 2;
	int y = 3;
	int z = x++ + ++y;
	x, y, z의 값을 구하시오
	1. x : x++로 인해 3
	2. y : ++y로 인해 4
	3. z : x++(증감 적용안됨. 2) + ++y(증감 적용됨. 4) = 6


	1-3. 논리 부정 연산자 : !(booleanValue) - 원래 값의 반대로(true -> false, false -> true)

 2. 이항 연산자

	2-1. 산술연산자 : +,-,*,/,%(더하기 빼기 곱하기 나누기-몫 나머지-몫)

	** 산술변환
	 - 기본적으로 이항 연산자의 연산은 두 피연산자의 타입이 일치해야 가능함
	 - 컴퓨터는 서로 다른 타입을 계산하지 못하므로 값의 손실이 적은 쪽으로 타입이 맞춰짐.
	 - double <- float <- long <- int <- byte

	2-2. 관계(비교)연산자 : 두 값의 크기를 비교하는 연산자
		- 크기비교(<, <=, >, >=)
		- 동등비교(==, !=)
		- 결과값 반환은 논리형(boolean)으로
		- 비교연산자는 흐름 제어문인 조건문(if), 반복문(for, while)에서 실행의 흐름을 제어할 때 주로 사용
		- 두 값을 자동타입변환을 통해 타입을 일치시킨 뒤, 비교가 진행됨
		- 다만 float과 double은 정밀도 차이 때문에 double을 float로 바꿔주어야 함
		- 참조자료형의 변수는 ==으로 비교하면 주소값을 비교한다.
		-> 실제값 비교를 위해서는 isEqual 메서드 사용

	2-3. 논리연산자 : 논리식의 and(&&), or(||)를 의미하는 연산자
		- &&(and) : TT - true / TF, FT, FF - false
		- ||(or) : TT, TF, FT - true / FF - false
		- 

	** 비트논리연산자(시프트연산자)
		- 기능은 논리연산자와 같지만, bit단위(2진수)의 연산만 가능
		- 피연산자가 1,0이라는 것과 산출 결과가 1,0이라는 점이 특징
		- 1은 true, 0은 false라고 생각하면 논리연산자와 차이는 없음
		- & : 논리곱(and - 교집합)
		- | : 논리합(or - 합집합)
		- ^ : 배타적 논리합(두 논리값이 동일해야 true(대칭차집합))
		- ~ : 부정(논리값의 반대 - 여집합)
