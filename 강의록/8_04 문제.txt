다음과 같은 문제가 자주 발생하고 있다.

예약 건수가 서로 다르다.
코드 변환 오류가 발생한다.
로그가 남지 않는다.
오류 발생 후 자동 재처리가 되지 않는다.
조건

다음 내용을 모두 포함하여 작성하시오.

위 상황에서 설계해야 하는 테스트 항목을 6가지 작성하시오.
각 테스트 항목을 확인하는 목적을 간단히 작성하시오.

 - 송신 DB와 수신 DB의 테이블값 비교 : 예약 건수가 두 시스템에서 다르므로 테스트 필요
 - 송신 건수와 수신 건수 비교 : 예약 건수가 두 시스템에서 다르므로 테스트 필요

 - 코드 매핑 결과 확인 : 코드 변환 오류 발생 시 매핑에 문제가 있을 수도 있음
 - 데이터 타입 및 길이 변환 확인 : 코드 변환 오류 발생 시 데이터 타입이 맞지 않거나 길이 변환이 되지 않는 등 데이터 형식의 변환이 되지 않았을 수도 있음
 - 전송 후 로그 기록 여부 확인 : 전송이 완료되면 로그가 남아야 하는데, 이에 문제가 생겼을 수 있음
 - 오류 발생 시 재처리 여부 확인 : 오류가 발생한 후 자동 재처리가 되지 않는다고 하는데, 재처리 자체에 문제가 생겼을 수 있음
