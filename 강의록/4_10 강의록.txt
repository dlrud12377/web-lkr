 < 4/10 강의록 >

	< Map >
		- Map 인터페이스가 별도로 존재
		- key와 value 두 개의 값으로 구성된다.
		- value의 값은 중복될 수 있으나, 인덱스의 역할을 하는 key는 중복되어선 안된다.

	
	< 람다식 문법 >
		- 반환타입, 메서드명을 생략하고 매개변수와 몸체 사이에 화살표를 쓴다.

		< 생략법 >
			1. 매개변수의 타입을 생략할 수 있다.
				ㄴ 매개변수가 두 개 이상이 ㄹ때 타입을 둘 다 생략해야 한다.

			2. 매개변수가 1개를 땐느 소괄호 생략 가능
				(x) -> {return x;};
				x -> {return x;}
				ㄴ 두개 이상일 때는 안됨

			3. 반환형이 void면 중괄호 생략 가능
				3-1. 또는 명령이 return 한 줄이면 return과 중괄호를 함께 생략 가능
					x -> System.out.println(x);
					x -> {return x;};
					x -> x;
