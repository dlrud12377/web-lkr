< GIT 세팅>
1. git 사용하기(초기 설정)
 (0). github 로그인
 (1). 폴더 생성
 (2). 폴더 우클릭 - git bash 
 (3). git config --global user.name (github 닉네임)
 (4). git config --global user.email (github 가입 이메일)
 (5). git init(initialize - 생성자 / 초기 값 지정)

2. 명령
 (1). 저장소(repository)
 (2). 버전 저장(commit) - 작성자, 날짜, 메시지 등 다양한 정보 기록가능
 (3). 원격 저장소로 업로드(push)
 (4). 원격 저장소에서 다운로드(pull)
 (5). 어떤 버전기 기록되어있는지 확인(log)

3. 사용 방식
 : 작업공간에서 작업 - 작업한 내용 스테이지에 업로드(명령어 add 사용)
(git add 파일명 -> 해당 파일을 추가)
(*git add . -> 현재 폴더의 모든 변경점을 추가)


git commit -m "message" : 버전기록
git log : 버전기록 확인
git reset 옵션 커밋ID : 되돌리기
--SOFT -> 커밋 내용은 사라지나 내용을 임시 저장 상태로 되돌림
--MIXED -> 임시 저장까지 취소, but 작업공간에는 남겨둠
--HARD -> 임시저장/작업공간 전부 삭제

HEAD : 최신 버전을 의미. 따라서 HEAD~1은 최신 버전에서 1단계 전 버전을 의미

원격 저장소에 올리기 전 커밋이 완료된 상태여야 함


< 정리 >

       add	  commit	    push
폴더  -> stage -> 버전기록 -> 원격 저장소에 저장

이 명령과정을 github desktop을 이용해 간단히 해결 가능
 - github desktop의 경우 자동 add, 메시지 적고 commit 버튼 누르기, push origin 버튼 누르기로 과정을 대체


< JAVA >
설치과정 생략

1. src 폴더
 - 소스코드가 저장되는 폴더
 - 패키지 단위로 폴더 생성, 그 안에 파일 위치
 - 작성하는 모든 파일이 이곳에 저장됨

2. JRE System Library
 - 프로젝트 실행에 필요한 코드들의 묶음
 - 기본적인 기능 탑재
 - 프로젝트 생성 시 자동 추가

3. 클래스
 - 자바 프로그램의 기본 구성 단위
 - 자바에서 모든 코드는 반드시 클래스 블록({}) 안에 있어야 함

4. 메서드
 - 클래스 안에서 정의된 함수
 - 기능

5. 자바 사용
 - 클래스 생성 - 메인 메서드 만들기 - 메인 메서드 내 코드 작성
